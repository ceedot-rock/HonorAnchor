    What this is — and what it is not

    • Recorded replay, not a live run. Every number on this page comes from the recorded run run-2026-10-31T103002Z (17 receipts, issued 2026-10-31T10:30:02Z–10:30:03Z). No scenarios, amounts, or outcomes were added.
    • Simulated cents. No real money moved. The recorded run reports payment_status: simulated-only and “No real payment was made in this run.” Denied spends were never booked.
    • Scripted inference. The provider is recorded as “scripted (deterministic, no model)”. No model was called and no API keys were used.
    • Receipts prove signature + canonical integrity only. The trail is a TypeScript reimplementation of CuNi-shaped check envelopes. It is not the verified Python cuni_envelope, and no CuNi-equivalence claim is made.
    • No live systems. No live Agent-Rider rail, no MCP calls, no x402 / on-chain payment, no Zetaris.
    • Fresh ephemeral keys. Ed25519 key pairs were generated in memory at runtime; only the issuer public key below was stored. Nothing else was stored.
    • No compression claims are made anywhere on this page.
